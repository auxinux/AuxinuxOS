# Codecs et decodage materiel: ce qui permet de LIRE, pas une application.
#
# Ex layer-multimedia.txt. Depuis le 2026-10-02, les applications (VLC, Elisa,
# Kdenlive, Audacity, GIMP) ne sont plus dans l'image: l'assistant de premier
# demarrage les propose (voir hors-socle.txt). Restent ici les codecs, dont le
# navigateur et les apercus de Dolphin ont besoin quel que soit le lecteur
# choisi, l'ordonnancement temps reel de l'audio, et le decodage materiel que
# le controle materiel interroge (vainfo).

ffmpeg
# Les plugins GStreamer conditionnent la lecture de la plupart des formats
# courants. Sans -bad/-ugly/-libav, une bonne partie des videos ne s'ouvre pas
# -- et l'utilisateur conclut que le lecteur est casse.
gstreamer1.0-plugins-good
gstreamer1.0-plugins-bad
gstreamer1.0-plugins-ugly
gstreamer1.0-libav
ffmpegthumbs

# rtkit accorde la priorite temps reel a PipeWire pour les utilisateurs du
# groupe audio. Sans lui, l'enregistrement multipiste decroche sous charge.
rtkit

# Decodage video MATERIEL (VA-API/VDPAU). C'est ce qui separe une lecture 4K
# fluide a 5 % de CPU d'un ventilateur a fond: le controle materiel de
# l'installateur s'appuie sur vainfo pour le dire a l'utilisateur.
va-driver-all
mesa-vdpau-drivers
vainfo
# Decodage materiel Intel (Quick Sync). va-driver-all n'installe que le pilote
# libre; celui-ci couvre les generations recentes, ou le libre ne sait rien
# faire. C'est la difference entre une video 4K a 5 % de CPU et un ventilateur
# a fond sur un portable.
intel-media-va-driver-non-free
