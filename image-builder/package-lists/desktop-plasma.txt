# Bureau KDE Plasma 6.3 (Debian 13), session Wayland.
#
# COSMIC a ete abandonne le 2026-09-12. Il n'existe dans AUCUN depot Debian
# (verifie: ni main, ni contrib, ni non-free) et il n'etait meme pas empaquete
# ici: build-cosmic-source.sh compilait cosmic-epoch et COPIAIT les fichiers
# dans le rootfs. Consequences: aucune mise a jour du bureau sur les machines
# installees, aucun `apt purge` possible, et surtout aucun retour a COSMIC
# apres un passage a GNOME ou KDE. Plasma vient de Debian: signe, corrige par
# l'equipe securite, purgeable -- donc reellement commutable.
#
# Liste EXPLICITE plutot que le metapaquet `kde-plasma-desktop`: l'image
# installe avec --no-install-recommends, donc ses Recommends (dont
# plasma-discover et plasma-welcome, tous deux ecartes ici) ne seraient pas
# tires de toute facon, et son Depends kde-baseapps ramene konqueror.

# --- Session ---------------------------------------------------------------

# Les DEUX compositeurs. La session par defaut est Wayland (kwin-wayland);
# kwin-x11 ne sert qu'a proposer une session X11 au greeter, filet de secours
# sur un GPU qui ne rend pas correctement en Wayland. Xorg est de toute facon
# present: sddm en depend FERMEMENT dans Debian (pas un Recommends).
kwin-wayland
kwin-x11

# SANS console de secours, reproduit en VM le 2026-09-09).
