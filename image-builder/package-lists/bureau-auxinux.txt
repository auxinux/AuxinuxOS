# Bureau d'AuxiNux OS: AuxiNux Shell (labwc + GTK 4), SANS le bureau Plasma.
#
# Decision d'aporler (2026-10-23): l'image n'installe plus le BUREAU KDE Plasma
# (plasma-desktop/workspace, KWin, systemsettings, kscreen, powerdevil,
# plasma-nm/pa, bluedevil...). Il reste propose en option dans le centre de
# controle (Reglages, « Bureau »). Les APPLICATIONS KDE restent (Dolphin,
# Konsole...): AuxiNux Shell leur donne deja ses couleurs (kdeglobals), elles
# ne tirent ni plasma-workspace ni KWin (verifie par apt-get -s sur Debian 13).
#
# Regle d'aporler (meme jour): une application AuxiNux installee REMPLACE son
# equivalent. AuxiPDF (AuxiOffice) -> plus d'Okular; AuxiText -> plus de Kate;
# AuxiMail -> plus de Thunderbird propose.
#
# Ce que ces paquets remplacaient de Plasma: voir retire-du-socle.txt (purge
# sur un rootfs reutilise, refuse par check-rootfs.sh).

# GARDES alors que le bureau Plasma part: le Shell s'en sert.
#  - plasma-integration: QT_QPA_PLATFORMTHEME=kde (bin/auxinux-session), et elle
#    tire breeze, dont les .colors servent au Shell pour ecrire le kdeglobals de
#    session (sans eux: applications KDE et centre sans mode sombre ni accent).
#  - xdg-desktop-portal-kde: publie org.freedesktop.appearance color-scheme lu
#    par auxinux-color-sync (AuxiText et les applications GTK suivent le mode
#    sombre), et le selecteur de fichiers des Flatpak (auxinux-portals.conf).
#  - polkit-kde-agent-1: agent d'autorisation de REPLI du Shell.
# Aucun des trois ne tire plasma-workspace ni KWin.
plasma-integration
xdg-desktop-portal
xdg-desktop-portal-kde
xdg-desktop-portal-gtk
