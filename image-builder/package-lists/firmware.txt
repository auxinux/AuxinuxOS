# Micrologiciels materiels (composant non-free-firmware, active dans les
# sources APT).
#
# REGLE, posee le 2026-09-13: l'ISO doit s'installer sur N'IMPORTE QUELLE
# machine grand public x86. On embarque donc TOUT ce qui peut se trouver dans
# un portable ou un ordinateur de bureau -- et rien d'autre.
#
# L'absence d'un micrologiciel ne produit aucun message comprehensible: la
# machine n'a pas de son, ou pas de WiFi. Et sans WiFi, l'utilisateur n'a meme
# pas le moyen de telecharger ce qui lui manque. C'est le genre de detail qui
# fait desinstaller un systeme.
#
# ECARTES VOLONTAIREMENT, avec la raison:
#   firmware-qcom-soc ............ 305 Mo de blobs Snapdragon (ARM). Le WiFi
#                                  Qualcomm des portables x86 (ath11k, ath12k,
#                                  QCA6390, QCA6698) est dans firmware-atheros,
#                                  verifie paquet en main.
#   firmware-netronome ........... cartes reseau de centre de donnees
#   firmware-marvell-prestera ....   "
#   firmware-cavium, -qlogic .....   "
#   firmware-myricom, -netxen ....   "
#   firmware-b43*-installer ...... ces paquets TELECHARGENT le micrologiciel
#                                  depuis Internet a l'installation: ils
#                                  echoueraient dans le chroot de construction
#                                  comme sur une machine hors ligne.
#   firmware-nvidia-tesla-* ...... branche proprietaire, sans rapport avec
#                                  nouveau.
#   firmware-ipw2x00, -ivtv ...... ces deux paquets DEMANDENT l'acceptation
#                                  d'une licence par debconf, et leur preinst
#                                  echoue dans un chroot non interactif:
#                                    « agree question could not be asked »
#                                    dpkg: error processing archive (--unpack)
#                                  On pourrait pre-repondre par
#                                  debconf-set-selections, mais ce serait
#                                  accepter une licence a la place de
#                                  l'utilisateur. Le materiel concerne --
#                                  Centrino 2003-2006, cartes d'acquisition TV
#                                  Hauppauge -- ne justifie pas de trancher
#                                  cette question a sa place.

# Edition ARM (arm64): ces paquets sont « Architecture: all », la liste vaut
# telle quelle. firmware-qcom-soc (ecarte ci-dessus) deviendra necessaire pour
# les portables Snapdragon; inutile dans une VM sur Mac Apple Silicon, premiere
# cible de l'edition. A ajouter alors avec le marqueur [arm64].

# --- Metapaquets de base ----------------------------------------------------
firmware-linux
firmware-linux-nonfree
firmware-misc-nonfree

# --- Reseau sans fil --------------------------------------------------------
firmware-iwlwifi
firmware-realtek
# Contient aussi ath11k/ath12k, donc le WiFi Qualcomm des portables recents.
firmware-atheros
firmware-brcm80211
# MT7921/MT7922: tres repandus sur les portables AMD recents.
firmware-mediatek
firmware-libertas
firmware-ti-connectivity
# Cles USB WiFi.
firmware-ath9k-htc
firmware-carl9170
firmware-zd1211

# --- Audio ------------------------------------------------------------------
# LE manque le plus grave sur un portable recent: sans SOF, aucun son sur la
# quasi-totalite des machines Intel et AMD depuis 2019.
firmware-sof-signed
firmware-intel-sound
# Amplificateurs de haut-parleurs, courants sur Dell/HP/Lenovo depuis 2021.
firmware-cirrus

# --- Graphique --------------------------------------------------------------
firmware-amd-graphics
firmware-intel-graphics
# nouveau: sans ces blobs, rien ne s'affiche sur une NVIDIA recente.
firmware-nvidia-graphics
# GSP, introduit avec Turing: nouveau en depend sur les cartes recentes.
firmware-nvidia-gsp
# Puces graphiques ASpeed des cartes meres de station de travail (42 Ko).
firmware-ast

# --- Reseau filaire et divers ----------------------------------------------
# Broadcom NetXtreme: presentes sur beaucoup de stations de travail Dell/HP.
firmware-bnx2
firmware-bnx2x
firmware-intel-misc
firmware-samsung
# Tuners TV.
firmware-siano
