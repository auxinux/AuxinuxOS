# Couche JEU (ex windows-support.txt).
#
# Steam n'est PAS ici: il est installe en FLATPAK a la demande (arbitrage du
# 2026-09-12), ce qui l'isole et evite de figer un client qui se met a jour
# tout seul dans l'ISO. Meme logique pour Heroic. Voir
# packages/windows-support/auxinux-windows-setup.
#
# Ce que la couche fournit: la pile Wine/Vulkan 64 ET 32 bits, les outils de
# mesure et de bridage, et Lutris pour lancer les jeux non-Steam.

wine
winetricks
dxvk

# Lutris N'EST PAS ici, volontairement. Les LANCEURS (Steam, Heroic, Lutris,
# Bottles) s'installent en Flatpak a la demande via auxinux-windows-setup, qui
# les presente avec une explication; la couche jeu fournit la PILE
# d'execution (Wine, Vulkan 64/32 bits, mesure et bridage). Une seule regle,
# donc: pile en DEB, lanceurs en Flatpak. Le Lutris de Debian 13 aurait en
# plus retarde d'une version majeure sur celui que le projet Lutris
# recommande.

# Vulkan 64 bits ET 32 bits. Les jeux Windows passes par Proton/Wine sont
# massivement 32 bits: sans les variantes i386, Vulkan retombe sur un rendu
# logiciel ou refuse de demarrer. L'architecture i386 est ajoutee par
# build-image.sh.
libvulkan1
libvulkan1:i386
mesa-vulkan-drivers
mesa-vulkan-drivers:i386
libgl1-mesa-dri
libgl1-mesa-dri:i386
vulkan-tools

# gamemode ajuste gouverneur CPU et priorites pendant une partie; mangohud
# affiche le compteur d'images.
#
# PAS de `gamemode:i386`: le paquet est « Multi-Arch: allowed », donc les deux
# architectures ne sont PAS co-installables et apt refuse net
# (« gamemode:i386 Conflicts gamemode »). Ce dont un jeu 32 bits a besoin, ce
# n'est pas le binaire ni le demon -- un seul demon suffit pour toute la
# machine -- mais les BIBLIOTHEQUES qu'il precharge, et celles-la sont
# « Multi-Arch: same ».
gamemode
libgamemode0:i386
libgamemodeauto0:i386
# mangohud, lui, est « Multi-Arch: same »: sa variante i386 s'installe a cote.
mangohud
mangohud:i386
goverlay
