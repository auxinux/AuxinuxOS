# Couche de compatibilite Windows.
#
# Wine seul ne suffit pas: il couvre les applications bureautiques, pas les
# jeux. La pile complete visee est en trois couches, dont deux s'installent a
# la demande en Flatpak (voir packages/windows-support/auxinux-windows-setup):
#   - applications  -> Bottles (prefixes isoles par application)
#   - jeux Steam    -> Steam + Proton
#   - jeux hors Steam -> Heroic / Lutris
# Les Flatpak ne sont PAS embarques dans l'ISO: Steam pese plusieurs Go et
# gonflerait l'image pour des utilisateurs qui n'en veulent pas.

# Le metapaquet `wine` tire wine64 ET wine32; `wine64` n'existe plus comme
# paquet separe sur Trixie. wine32 exige l'architecture i386, ajoutee par
# build-image.sh.
wine
winetricks

# q4wine RETIRE: interface Qt abandonnee en amont, et elle exposait la gestion
# brute des prefixes Wine -- precisement ce qu'un utilisateur non technique ne
# doit pas avoir a manipuler. Bottles le remplace.

# Pile Vulkan: indispensable a DXVK et VKD3D, donc a Proton et aux Flatpak de
# jeu. Sans elle, les jeux retombent sur OpenGL ou ne demarrent pas.
mesa-vulkan-drivers
libvulkan1
vulkan-tools

# gamemode: bascule le gouverneur CPU et les priorites pendant une partie.
# mangohud: superposition FPS/temperatures, utile pour diagnostiquer.
gamemode
mangohud
